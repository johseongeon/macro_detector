# Red Team — 매크로 재현 도구

> **내부 전용.** 탐지 모델의 학습·평가 데이터를 만들기 위한 도구입니다.
> 테스트베드(`testbed/`)와 사내 스테이징 환경에서만 사용하며, 외부 서비스를 대상으로 실행하지 않습니다.

| 레벨 | 유형 | 예시 도구 | 주요 탐지 신호 |
|---|---|---|---|
| L1 | 단순 반복 클릭 | AutoHotkey, pyautogui | 주입 플래그, 일정한 클릭 간격 |
| L2 | 브라우저 자동화 | Selenium, Playwright | `isTrusted`, 자동화 흔적, 순간 이동 좌표 |
| L3 | 사람 흉내 | 베지어 궤적, 무작위 지연 | 속도·가속도 분포, Fitts' law 적합도 |
| L4 | 사람 궤적 재생·생성 | 녹화 재생, GAN 궤적 | 교차 세션 지문, 장치 폴링 특성 |

## 규칙
- 레벨마다 `l1/`, `l2/` … 하위 폴더에 재현 스크립트와 실행 방법을 둡니다(Phase 1부터 추가).
- 테스트셋용 도구 일부는 학습 데이터에 쓰지 않습니다(처음 보는 매크로에 대한 일반화 평가).
